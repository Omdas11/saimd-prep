# SA-IMD Prep

Live: https://saimd-prep.vercel.app

SSC Scientific Assistant (IMD) Paper-I preparation site — 380 solved PYQs (2022 + 2017),
official-key flashcards, study notes, and a timed 200-question Paper-I mock
(Reasoning 50 / GA 50 / Physics 100, 2 hours, -0.25 negative marking) with
auto-submit and section-wise results.

Provenance badges mark each question as original, reconstructed, or verified.
